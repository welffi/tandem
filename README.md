# tandem

a windows video player and editor. it plays every audio track of a video at once, and has a full timeline editor with keyframes, text, effects, a library and export

made with rust and egui. part of [welffi hub](https://github.com/welffi/welffi-hub)

## how to download

1. get `tandem.exe` from the [latest release](https://github.com/welffi/tandem/releases/latest) and run it, or open it from welffi hub
2. the first time it runs, it downloads ffmpeg for you
